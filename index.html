Self-Service Reporting & Dashboard Builder

Let business users build their own reports and dashboards.

Featured Hackathon 2024 prize winner · Regulatory documentsAI · Python

PDF PII redaction tool

Detects and redacts personal data in regulatory PDFs.

Problem
Regulatory documents can contain personal data that has to be found and redacted, page by page.
My role
Built the web application and the detection pipeline in Python.
Solution
A Flask app with login, forms, CAPTCHA and session-based uploads, plus REST/JSON endpoints for analysis and file operations. A config-driven pipeline extracts PDF text, calls a pluggable analyzer and writes highlighted PDFs that open in the browser. Detection runs on Microsoft Presidio with YAML-defined recognizers, spaCy and Hugging Face Transformers models, or AWS Comprehend through Boto3, with entity lists and confidence thresholds set in configuration. Overlapping detections are scored and ranked before highlighting.
Outcome
Reviewers see detections highlighted in the PDF, and the detection engine can be swapped through configuration without rewriting the web layer.

PharmaData pipeline · AWS

Clinical trial data integration

An automated pipeline that keeps clinical trial data current from public registries.

Problem
Clinical trial information is distributed across public registries, making it difficult to maintain an up-to-date, consistent view of study data. Collecting and reconciling updates across sources introduces operational overhead and makes reliable access to current information more challenging.

Developed an automated data integration pipeline that retrieves clinical trial information from EudraCT and ClinicalTrials.gov, monitors updates, processes incoming data, and stores it in PostgreSQL.

Established a unified workflow for collecting and maintaining clinical trial data, improving accessibility and reducing reliance on fragmented data-handling processes.
